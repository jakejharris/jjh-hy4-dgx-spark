# Receipts (`receipts/`)

Every measured claim in `card/claims.json` names one receipt file here, except the two GGUF baseline sizes (`baseline.gguf.size`, `baseline.gguf.bpw`). Those, and the component rows, name our run notes (paths starting `S:`), which are not in the kit.

## What a receipt holds

The raw output of the run behind the number: the bench or needle JSON with every run, the teacher score file, the token comparison, or what `launch/collect_receipts.py` wrote after a boot (launch settings, per-rank load lines, memory minima, known-answer reply). Bench, needle and draft rows also carry the boot record the run was checked against (`boot-plain.json`, `boot-dfly.json` or `boot.json` beside the receipt): trunk, drafter, head, layers, context and transport as the server reported them.

`tools/fill_claims.py` copies these files from a boot's outputs (see `card/fill-map.json`), after checking their labels against the claim. It replaces machine host names with `node1` to `node4` and home folders with `~`; values are copied unchanged. `launch/collect_receipts.py` redacts the same way as it writes (host names become `node1` to `node4` in rank order), so `tools/check_kit.py` passes right after a boot; `python3 launch/collect_receipts.py --redact DIR` redacts receipts an older copy wrote.

## Names inside the receipts

Receipts keep the names the runs used. `winB` and `winC` are our names for two bench sessions on 2026-11-21. Labels starting `winC` and folders such as `/tmp/hy4-winC-c10/serve` (steps `c02` to `c10`) are the session behind most receipts. `winB` names folders from the earlier session: `~/hy4/int/winB-bin/` holds the release binaries, and the draft cutoff at 0.85 (`speed/exl3-4k/cutoff.json`) ran there. A `prompt` path such as `~/work/max/hy4/kit/bench/prompts/pp-32k.txt` is where the kit sat on the bench machine; the same file is in `bench/prompts/`.

## Folders

Folder names carry the build: `exl3` is the full quant (the default), `lossless` the lossless trunk option.

- `widths/`: the 4K table that picked the full quant's trunk width (`width_table.json`).
- `quality/`: top-1 agreement score files per build and prefix set (`teacher-exl3.json`, `teacher-lossless.json` on the familiar set; `teacher-fresh-exl3.json`, `teacher-fresh-lossless.json` on the fresh set), written by `eval/agreement.py score`; the drafted path scored against the reference (`drafts-top1-exl3.json`, with its boot record `drafts-top1-boot.json`).
- `speed/exl3-4k/`: the full quant at 4K. Plain runs (`prose-plain.json`, `code-plain.json`, `prose-nothink-plain.json`, boot record `boot-plain.json`); the drafted boot with the repeat option off (`prose-dfly.json`, `boot-dfly.json`) and its plain-versus-drafted token comparison `draft_diff.json` (tokens that differ and the first differing position, per prompt); `"draft": false` requests against plain (`draftoff_vs_plain_diff.json`); the draft cutoff at 0.85 (`cutoff.json`); the other drafted runs with the repeat option off, under the bench's own names (`4b6b-4k-dfly_*.json`).
- `speed/exl3-4k-rs/`: the full quant's drafted runs with the repeat option on, the kit default (`prose-dfly.json`, `code-dfly.json`, `draft_diff.json`, `boot-dfly.json`), plus the runs behind the repeat-option tables under the bench's own names (`4b6b-4k-rs_*.json` on, `4b6b-4k-dfly_*.json` off).
- `speed/exl3-4k-cutoff05/`: the draft cutoff at 0.5 (`cutoff_summary.json`).
- `speed/lossless-4k/`: the lossless trunk at 4K, plain and drafted (repeat option on), with `draft_diff.json` and both boot records.
- `long/exl3-32k/`, `long/lossless-32k/`: the 32K prompt runs (`pp32k.json`, `boot.json`). `long/exl3-128k/`: the full quant's 128K needle runs, thinking on (`niah-128k-on.json`, boot record `boot.json`) and thinking off (`niah-128k-off.json`, boot record `boot-off.json`). - `parts/split-78l-4b6b.log`: the full quant's 78-layer split on one Spark (`tools/split_ranks.sh FULL_PACK OUT --trunk 4b6b --check`, the release `tf-hy4-oracle`, 2026-11-21 17:08:15 to 18:16:38 UTC), the job's own log with home folders written `~`.
